# Founders media

- `videos/` : compressed web videos (MP4, H.264), named `video-1.mp4` ... `video-6.mp4`
- `posters/` : poster images for each video (`video-1.jpg` ...)
- `images/` : photographs for this section

Then register the files in `assets/js/manifest.js` under `sections["founders"]`.
Keep original, uncompressed footage outside the repository.
